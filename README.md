# OpenFrameworks Arena Game - Centurion of the Forest

## Overview
This project is a 3D game developed using openFrameworks as part of a Games Computing coursework assignment.

The game features a fully playable 3D environment, custom game logic, player controls, enemy interactions, scoring systems, and user interface elements. 
Assets and 3D models were created and prepared using Blender before being imported into the project.

## Features
3D gameplay environment,
Player movement and camera controls,
Enemy AI and combat mechanics,
Health and scoring systems,
Interactive user interface,
Custom 3D models and assets created with Blender,
Real-time rendering using openFrameworks

## Technologies Used
C++,
openFrameworks,
Visual Studio,
Blender
